

# DataFrameReporter

## Описание проекта

Проект представляет собой класс `DataFrameReporter` для автоматического формирования отчёта по DataFrame библиотеки pandas.

Класс помогает быстро оценить качество и структуру данных перед проведением анализа. Он выводит:

- количество строк и столбцов;
- количество полных дубликатов и их долю;
- описательную статистику с помощью `describe()`;
- общее количество пропущенных значений и их долю.

Класс поддерживает настройку формата отображения чисел и процентов, а также включение статистики по всем типам столбцов.

## Установка и запуск

1. Клонируйте репозиторий:

```bash
git clone https://github.com/vikaonline2022/mle-razrabotka-v-ide.git
```

2. Перейдите в папку проекта:

```bash
cd mle-razrabotka-v-ide
```

3. Создайте виртуальное окружение:

```bash
python3 -m venv venv
```

4. Активируйте виртуальное окружение:

```bash
source venv/bin/activate
```

5. Установите необходимые библиотеки:

```bash
pip install -r requirements.txt
```

6. Запустите программу:

```bash
python3 main.py
```
